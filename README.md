# 🥗 SnackWise

### Healthy Snack Discovery Website

SnackWise is a modern and user-friendly healthy snack discovery website designed to help users explore tasty and nutritious snack options based on their cravings, goals, preparation time, and preferences.

## 🌐 Live Website

[Visit SnackWise](https://enchanting-league-505362.framer.app)

## 🎯 Project Objective

The objective of SnackWise is to make healthy snack discovery simple, attractive, and enjoyable. The website uses a fresh visual design, clear information hierarchy, food imagery, reusable cards, and intuitive navigation.

## ✨ Features

- Browse snacks by craving
- Explore snacks based on daily goals
- Popular snack recommendations
- Snack Matchmaker
- Quick snacks based on preparation time
- Recipe of the Moment
- Nutrition information
- Favorite/save functionality
- Responsive design
- Interactive UI elements

## 🎨 UI Design

The design uses:

- Fresh and natural color palette
- Modern typography
- Rounded cards
- Consistent spacing
- Food-focused imagery
- Reusable UI components
- Responsive layouts
- Clear visual hierarchy

## 🛠️ Tool Used

**Framer**

Framer was used to design and develop the website, create reusable UI components, build responsive layouts, add interactions and animations, and publish the final website.
